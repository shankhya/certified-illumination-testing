# Supporting calibrated prediction corollary

Place this folder beside `illumination-testing` and
`illumination-testing-stability`. Python3.10+ and its standard library suffice:

    python -I -O -B verify_prediction.py --check-faults --output verification.json
    python -I -O -B predict.py observation.json --output prediction.json

The observation JSON contains arrays `y` (15 sample measurements), `testWhite`
(15 white-response estimates) and `targetWhite` (9 white-response estimates).
Use decimal or rational strings, or integers, so evaluation is exact. Order
tests as A,D65,FL2,FL7,FL11 and targets as FL3,FL8,FL12, XYZ within each light.
Responses use white Y=1. The result is a response vector and need not be
generated by a single physical reconstructed spectrum.

The predictor is `V*(y-testWhite/2)+targetWhite/2`. The supplied calibration
data concern the actual operators. Each sample measurement error is at most
epsilon=0.00005. Each actual normalized kernel has L1 error at most mu from
its nominal kernel, and every white-coordinate estimate has error at most
gamma. Actual reflectances remain passive and are within uniform distance
rho of the g=0.0355/nm slope class. Subject to these assumptions, error is at
most0.01 in normalized XYZ infinity norm throughout

    (mu+gamma)/0.000073935629 + rho/0.005633164098 <= 1.

All allowances are nonnegative and the printed denominators are conservative.
Using only nominal white responses incurs gamma<=mu, giving the conservative
replacement2*mu for mu+gamma. Calibration exposures are not included in the
five reflectance-sample test count. Calibration data include target whites.
The verifier cannot establish these physical assumptions from an input file.

The checker reconstructs the rational coefficients from the core's duals,
checks continuous stability bounds and exact counterexamples, and verifies
the noise/calibration geometry. It proves upper error below0.01 for the four
included examples and lower error above0.01 for every smaller constituent
selection. Five tests therefore suffice and fewer do not for this declared
task. The same central-observation argument covers deterministic adaptive
selection with adversarial Cartesian bounded noise; it does not cover
stochastic or randomized expected-error claims.

This is a classical optimal-recovery consequence supporting the illumination
testing study, not a novel recovery principle or a claim that V is the exact
minimax optimizer. The shared-SPD stability bound has not been transferred to
this fixed predictor. No perceptual-error or arbitrary-mixture test-count
claim is made. Source-data attribution and licenses are in the sibling core.
This is an internal research artifact; no public release is authorized.
